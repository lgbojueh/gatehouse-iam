# Portfolio entry

**Gatehouse IAM — Secure Identity & Access Platform**

Security-focused full-stack application demonstrating authentication, role-based authorization, administrator access management, and audit logging. Server-side policy checks enforce least privilege across user, analyst, and admin roles.

**Stack:** React, TypeScript, FastAPI, JWT, scrypt, SQLAlchemy, SQLite/PostgreSQL-ready, Docker, GitHub Actions

**Suggested portfolio bullets**
- Server-side RBAC protects analyst and administrator API routes rather than relying on frontend-only hiding.
- Security audit trail records authentication and privilege-management events.
- Automated tests verify role boundaries and unauthorized access behavior.
